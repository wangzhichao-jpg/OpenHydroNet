# 公开人工示例

全部为独立构造的验证/教学数据，不含真实工程机密或厂家授权性能资料，不能直接用于选型。

- `closed-loop.ohn.json`：20 ℃双末端闭式循环。循环约 31.178 m³/h、泵扬程 18.499 m；T2 供需不足应有提示，效率未提供时输入功率为“—”。这组数是本实现回归参考；独立手算验证见 `tests/test_solver.py`，不是第三方工程认证。
- `benchmarks/`：5×5、10×10、20×20 对称管网，可独立推导线性水头和纵向零流；性能实测条件见 `docs/VALIDATION.md`，不代表任意同规模复杂网络都同样快。
- `single-line.json`：单线对称展开 API 的人工模型；`scan-settings.json` 类扫描示例均为独立稳态，不是时间动态。
- `device-library.ohnlib.json`：人工 H=32−180000Q² 基准泵和线性 Kv85 阀。曲线流量单位 m³/s，点文本 m³/h，基准转速 1450 rpm 是教学设定；无效率数据。通过“导入库 JSON（副本）”使用，按 UI 明确生成新库 ID，不自动改工程设备。
- `parameter-update.csv`：对应闭式示例的 P2/P3。在“导入参数表”选管段，映射 `id→id`、`diameter→diameter_mm`，输入单位选择 **mm**。预览应只显示两项 0.065→0.05 m，确认后可一次撤销；长度/连接不变。更新后的真实工作点需重新计算，不能用原结果充数。

## preview.3 人工高阻比复测

`high-resistance-regression.ohn.json` 是与 `test_solver_robustness.py` 正耗水用例同口径的原创制造解：先指定 H，再指定正向 Q，用 R=ΔH/Q² 和连续性生成阻力/需求。**不是论文表格，不是实际闭式供热设计，也不验证 Darcy 或厂家精度。**

- 6 节点、10 支路，R 从 4 到 8e8 s²/m⁵，最大/最小比为 2e8（约 8.30 个数量级）。
- 直接打开工程并计算；节点 n0…n5 的测压水头应为 **100、99、98、97、96、95 m**。
- 支路 e0…e9 的预期流量 [m³/s] 依次为 **0.5、0.2、0.08、0.0005、0.0001、0.02、0.006、0.0002、0.00005、0.002**；显示 m³/h 时乘 3600。
- 定压 n0 的边界供入量应为 **0.522 m³/s**；其余节点需求均正。质量残差 ≤1e-8 m³/s，能量残差 ≤1e-5 m；各节点水头最大偏差 ≤1e-5 m。流量比较建议相对误差 ≤1e-5，不只看舍入后的显示位。
- 可通过节点/支路结果表复核；几何布置只是示意，不定义管长。本例支路是直接等效阻力，没有管径/沿程物性标定意义。
