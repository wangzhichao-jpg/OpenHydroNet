### 操作方式与人工覆盖边界

- **自动驱动**：Playwright 启动/操作原始便携 EXE，调用真实随包 Python。R3 的保存/打开路径和未保存确认由脚本返回并记录（`dialogs.jsonl`）。Excel 用现有 Excel 16 COM 打开 CSV、读回单元格文字。
- **原生对话框检查**：R4-W4-07 不拦截对话框，实际生成 Windows“保存工程”和“工程尚未保存”窗口，用 PrintWindow 截图，再发送 WM_CLOSE 取消；这不是人工鼠标点击。最终退出的代答仅用于清理。
- **截图复核**：由 PC 端助手阅读截图，检查中文、图标、PDF 表格、运行按钮；**没有用户人工逐项复核**。截图只包含产品窗口/单个对话框；保存对话框导航栏含个人云盘名称，已模糊。
- **R1 准备方式**：API 下载的原包没有网络标记，显式写入与浏览器下载等价的 Zone.Identifier（ZoneId=3，GitHub 来源），ZIP 内容字节未变；Shell.Application CopyHere 使用资源管理器解压引擎。不能把该过程写成“用户已亲自用浏览器下载并双击”。
- R2/R3/R4 用的树来自已解压的原始 ZIP，**2,890 个文件逐字节一致**。复制测试树不是重打包，也不替代草稿附件；该树的启动结果**不计为 R1 冷启动**。

## 3. R1 首次冷启动——阻断原因与补测要求

### 已做的准备与无效观察

前三个临时目录均为全新资源管理器解压，ZIP 和 EXE 都确认 ZoneId=3，没有运行 `验证计算.cmd` 或随包 Python 预热。解压后通过信号立即触发启动器：

| 临时目录 | 解压耗时 | 完成后发出启动信号 | 是否形成有效产品启动测试 |
|---|---:|---:|---|
| 冷启动-1 | 132.22 s | 32 ms | **否**：留有下载安全警告截图，但未完成确认、未进入产品工作台；随后确认桌面锁屏 |
| 冷启动-2 | 131.09 s | 43 ms | **否**：原生下载安全警告在隐藏辅助窗口中等待确认，未启动 EXE |
| 冷启动-3 | 127.80 s | 34 ms | **否**：已观察到可见的 “Open File - Security Warning / Unknown Publisher”，但锁屏下发送按钮消息无法实际确认；没有产品进程启动 |

- 第 1 次安全警告截图保存在 `截图/R1-1/`（捕获到警告不代表已确认运行）；第 2 次辅助进程的原生警告句柄经检查为 `visible=False`；第 3 次改为正常窗口后捕获了安全警告。随后查询前台确认是 **LockApp**。这些都是**测试环境/脚本障碍，不是 preview.5 的失败证据**。
- 3 次观察脚本均在 150 s 后退出等待。**150 s 是观察器超时，不是产品启动耗时**；记录中的 `success=false` 表示观察器未完成，不能拿它判定 W4-06 仍存在。
- 原始诊断 JSON/脱敏日志在 `诊断-非有效R1/`；警告截图 `截图/R1-3/01-下载安全警告.png`。相关辅助进程已停止；无本包 EXE/Python 残留。三份无效尝试的临时解压目录随后已清理，测试用主目录与原 ZIP 保留。
- 已给 `r1-cold.ps1` 增加锁屏前置检查：锁屏时立即停止，不再重复解压/等待。

### 必须补做（不能用 R2 或 R3 代替）

1. 用户在 PC 上解锁、保持交互桌面打开；不需要提供密码给助手。
2. 使用**两个新目录**（建议 Round 4、5），每次由同一个已校验 ZIP 解压，确认 ZIP 与 EXE 带 ZoneId=3。
3. 解压完成立即 ShellExecute（双击同一路径），确认“运行”；不先执行验证脚本、Python 导入、哈希扫描解压后的运行时等预热步骤。
4. 分别记录从“运行”到启动窗口、到工作台的耗时、递增等待秒数；超过 10 s 时记录“比平时慢”反馈，工作台出现后确认启动窗口消失。
5. 每个目录再启动一次、打开公开示例计算 T2=13.679，并检查退出后进程。
6. 当前 ZIP 在 `artifacts/release-preview.5/`，不必重新下载。示例命令（在本记录目录运行，Round 不可复用现存目录）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\r1-cold.ps1 -Round 4 -Zip '<仓库>\artifacts\release-preview.5\OpenHydroNet-0.1.0-preview.5-win-x64.zip'
powershell -NoProfile -ExecutionPolicy Bypass -File .\r1-cold.ps1 -Round 5 -Zip '<仓库>\artifacts\release-preview.5\OpenHydroNet-0.1.0-preview.5-win-x64.zip'
```

脚本的原生鼠标操作仍需解锁桌面，计算结果截图必须再复核，不能仅凭脚本返回码填“通过”。
