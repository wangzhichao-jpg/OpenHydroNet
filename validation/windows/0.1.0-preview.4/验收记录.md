# OpenHydroNet 0.1.0-preview.4 Windows 真机验收记录

依据：[`docs/releases/HANDOFF-0.1.0-preview.4.md`](../../../docs/releases/HANDOFF-0.1.0-preview.4.md) 第 2 节。新版验收，**不继承 preview.2/preview.3 的结论**。
结果栏只能填：**通过 / 失败 / 跳过（写原因） / 未执行**。失败必须附截图；未做的不要填“通过”。
截图在本目录 `截图/`（只截应用窗口或单个对话框），原始数据见 `raw-results*.jsonl`、`dialogs*.jsonl`、`offline-run.log`，导出文件副本在 `导出物/`。

## 验收方式（如实说明）

- **真机、真包、自动驱动**：在用户 PC（Windows 11 实机）上运行未改动的便携包 `OpenHydroNet.exe`；界面操作由 PC 端 agent 用 Playwright（仓库 `node_modules`，与 `tests/ui.*.cjs` 同一机制）驱动，脚本 `drive.cjs` / `lib.cjs` / `probe-stale.cjs` 在本目录，可复跑：`node drive.cjs main|close|save`。
- **P0 与 P1 中系统原生对话框由脚本代答**：文件“保存/打开”对话框直接返回中文路径；“未保存修改”确认框按按钮文字选择，每次的提示文字、按钮与选择记录在 `dialogs*.jsonl`。原生对话框的真实外观与按钮另在 W4-04 抽查中验证（不代答，截图后用 Windows 消息点击按钮）。
- 关闭窗口用 `BrowserWindow.close()`，与点击标题栏 × 触发同一关闭流程；进程检查用 PowerShell `Win32_Process`，只统计可执行路径位于本包目录内的进程。
- CSV 用 Excel 16（COM `Workbooks.Open`，与双击打开同一导入路径）打开并读回单元格文字核对。
- **W4-04 抽查**：给 ZIP 写入与浏览器下载相同的“网络标记”（Zone.Identifier，ZoneId=3），用资源管理器引擎解压，以 ShellExecute（与双击同一路径）启动，并验证真实原生对话框。发现首次启动超时，见 W4-06。
- **P1-1** 用设置程序同一系统调用实时切换 100% / 125% / 150% 缩放（结束后恢复 150%）；**P1-2** 关闭 Wi-Fi 无线电（等同快速设置中关闭 WLAN），断网下重跑全部 P0，结束后恢复联网（7 s）。

## 附录 A：检查残留进程（只查本包，不结束其他软件的 python）

PowerShell（把路径换成实际解压目录的一部分）：

```powershell
Get-Process OpenHydroNet,python -ErrorAction SilentlyContinue |
  Where-Object { $_.Path -like '*OpenHydroNet-0.1.0-preview.4-win-x64*' } |
  Select-Object Id, ProcessName, Path
```

无输出 = 无残留。也可用任务管理器 → 详细信息 → 右键列标题 → 选择列 →“映像路径名称”，只看路径在本包目录下的进程。发现残留时记录 PID 与刚才的操作，不要“结束所有 python.exe”。

## 附录 B：隔离配置启动（推荐）

避免读写 `%APPDATA%\OpenHydroNet` 中旧版本的草稿与设置。在解压目录的地址栏输入 `cmd` 回车：

```bat
set "OHN_PROFILE=D:\OHN验收\预览4\profile"
start "" OpenHydroNet.exe
```

`profile` 目录内含浏览器缓存，不要提交或外发。
