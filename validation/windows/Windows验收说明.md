## 一、只想先快速验证，请按这个顺序

1. 从 WinSCP 下载 Windows-validation.zip 总包及旁边的 .sha256 文件，校验后解压一次即可。压缩包内的根目录名是“OHN验收”，里面已经有完整软件。请放在较短的可写路径，里面应直接看到 00/01/02/03 文件，避免反复套目录触及旧版 Windows 解压路径长度限制。
2. 双击“00-请先阅读.html”（也有同内容 TXT）。不需要安装 Node、Python、SciPy，也不需要账号或管理员权限。
3. 可双击“01-校验文件.cmd”，按清单逐文件核对已经解压好的软件和工具；不下载、不安装。若 PowerShell 被执行策略阻止，可用下一节的总包 SHA-256 手工校验，直接继续 02/03，不需要关闭安全功能。
4. 双击“02-内核自动检查.cmd”：使用随包 Python 检查依赖、20/80 ℃算例和 XLSX；结果在 feedback 中。它不代替桌面验收。
5. 双击“03-启动隔离测试.cmd”，在软件中按第三节做 P0 测试。请只用本包的人工示例，不打开您的真实工程。
6. 正常关闭软件，等 5 秒。在“反馈记录.csv”或“反馈记录.txt”填写实际结果，再双击“04-收集反馈.cmd”（不能运行也可手工交反馈）。
7. 将 feedback 下新生成的 collected-时间戳 文件夹和填写后的反馈记录、截图打包发回即可。不需要上传整个软件目录或配置目录。

建议先完成 P0，约 20–35 分钟；有时间再做 P1 扩展。失败的项目记录报错即可，不必反复折腾，也不要为通过测试而关闭杀毒软件或改系统安全策略。

## 二、目录、校验和手工备用操作

本资料包结构：
- app/：已经从原版候选 ZIP 完整解压的便携软件，二进制/运行代码未修改，不需要您再解压一层。

- tools/：本地校验、检查、收集脚本；不下载东西、不安装服务、不自动上传。

必须先完全解压总包，不能直接在压缩文件浏览窗口内运行程序。请选择您有写权限的位置；建议桌面下“OHN验收”，不要再套一层长名称目录。不要放进 Program Files，不使用已有工程目录。

来源候选为 OpenHydroNet-0.1.0-preview.2-win-x64.zip，220,320,845 字节；其原始摘要是 cb01685e7d13678e97649ae34091a1c43315bb636533d5689ff9f1c09199128f。本验收总包有额外工具，所以其摘要不同，请用总包旁边的 .zip.sha256 校验总包，不要拿来源候选摘要误比总包。

脚本被阻止时：
1. 在下载总 ZIP 的目录中，用资源管理器地址栏输入 cmd 并回车，执行：
   certutil -hashfile OpenHydroNet-0.1.0-preview.2-Windows-validation.zip SHA256
   将输出与旁边 .zip.sha256 文本的 64 位值比较；不同则先停止，重新传输并反馈，不继续运行。
2. 用 Windows 自带“全部提取”完整解压总包一次。应已有
   OHN验收\app\OpenHydroNet-0.1.0-preview.2-win-x64\OpenHydroNet.exe。
3. “02-内核自动检查.cmd”和“03-启动隔离测试.cmd”是普通批处理，仍可运行。
   若不运行自动检查，也可进入软件目录双击原有“验证计算.cmd”；记录 SUCCESS/FAILED，但它检查项目少于本资料包的自动检查。
4. PowerShell 收集脚本不能运行也不影响人工验收，填 TXT/CSV、保存截图与 feedback 内的 core-check-* 文件夹即可。
5. 不要求修改 ExecutionPolicy、绕过 SmartScreen、关闭防病毒或安装未知运行库。若安全软件阻止，保留告警文字/截图反馈。

03 启动器只在该进程里设置 OHN_PROFILE=本资料包\feedback\test-profile，并清除可能干扰的开发环境变量；不会修改系统全局环境变量，也不读写原来的 OpenHydroNet 用户配置。
请用 03 启动，不直接双击 EXE（直接启动会使用默认用户配置）。如您过去从未使用本软件，也仍建议使用隔离启动器。
01 只核对，不改动已有文件。解压失败或要重做时先保留现场，把旧“OHN验收”目录重命名，再将总包解压到新目录，不能删除自己的工程。SHA256SUMS 和清单描述原始包；填写反馈、生成日志后，反馈文件变化是正常的，不等于原软件已被篡改。
