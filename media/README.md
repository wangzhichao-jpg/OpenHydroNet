# 视频交付记录

软件：0.1.0-preview.1。要求两条真实界面视频：约 5 分钟介绍、约 2 分钟快速上手。

当前状态：制作流程开发中，尚不能称为视频正式交付。实际 MP4、SRT、旁白和质量检查将在这里记录。

制作必须来自实际 Electron 运行和公开 `examples/closed-loop.ohn.json`，不使用设计稿冒充功能；不放未发布仓库链接/二维码，不虚构性能/用户案例。

本地工具拟采用 FFmpeg（H.264/AAC）、eSpeak NG 离线中文合成、Noto Sans CJK 字体。无背景音乐、不调用付费服务、不上传工程到云服务。若本地旁白可懂度不足，应明确作为待审核候选，不伪称真人试听通过。
