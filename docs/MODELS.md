# 公式、设备模型与适用范围

版本：0.1.0-preview.5，算法 `sparse-head-flow-newton-trf-v2`。源实现见 `src/openhydronet/physics.py`、`solver.py`。本文件定义本项目独立构建的物理方程与数值求解算法。

## 1. 符号、单位和守恒

内核一律 SI：长度 m、时间 s、体积流量 Q [m³/s]、质量流量 [kg/s]、压力 Pa、密度 ρ [kg/m³]、运动黏度 ν [m²/s]。显示支持 m³/h、kg/h、t/h、L/s，不通过单位名称推定密度。质量流量 ṁ=ρQ；t/h=3.6ρQ；kg/h=3600ρQ。

支路方向为 source→target，Q 可负。节点需求 d>0 为向外漏水/取水，d<0 为补水；闭式末端不是节点耗水。非定压节点：ΣQ_out−ΣQ_in+d=0。定压节点由边界补足，结果 `boundary_supply_m3_s=ΣQ_out−ΣQ_in+d`，正数为边界供入网络。

节点求解变量为**测压管水头** H=z+p_g/(ρg)。p_g 为表压，g=9.80665 m/s²。压力水头为 p_g/(ρg)=H−z，总水头还包含 v²/(2g)。本模型使用集中节点、不单独定义节点速度；不等径支路的动能变化应通过工程等效局部损失描述。本版本不自动提供完整变截面动能修正。因此 H 不能宣传为总水头。

正常支路能量：H_source−H_target=h_loss(Q)−H_pump(Q)。闭式循环沿一周标高差相互抵消。建筑高度影响静压、绝压和汽化风险，不应简单叠加为循环泵扬程。

p_abs=p_g+p_atm。缺省当地大气压 101325 Pa 是公开假设，可编辑。水温为全网单一等温值。汽化筛查采用 Antoine 近似饱和压力（约 1–100 ℃，0 ℃按 1 ℃筛查），仅判断单相假设风险，不代表 NPSHa/NPSHr 校核，更不是汽蚀诊断。

## 2. 水物性

支持纯水 0–100 ℃，不含乙二醇、防冻液和加压高温水。密度采用常见 Kell 型经验近似：

ρ=1000[1−((T+288.9414)/(508929.2(T+68.12963)))(T−3.9863)²]。

动力黏度 μ=2.414×10⁻⁵·10^(247.8/(T+133.15)) [Pa·s]，ν=μ/ρ。20 ℃应约为 998.2 kg/m³、1.0×10⁻⁶ m²/s。经验近似不等价于 IAPWS 高精度物性，也没有多温区耦合。

## 3. 管道与局部阻力

A=πD²/4，v=Q/A，Re=|v|D/ν。

Darcy–Weisbach：h_f=f(L/D)v|v|/(2g)。f 是 Darcy 摩阻系数（不是 Fanning）。

- Re≤2300：f=64/Re；实现使用等价有符号泊肃叶表达 h_f=128νLQ/(πgD⁴)，在 Q=0 不做除零，不引入虚构最小流量。
- Re≥4000：Haaland 显式近似 f=[−1.8log10((ε/(3.7D))^1.11+6.9/Re)]⁻²。
- 2300<Re<4000：x=(Re−2300)/1700，s=x²(3−2x)，f=(1−s)f_lam+s f_turb。这是本项目明确的平滑过渡约定，不声称过渡区本来就具有唯一确定规律。

局阻两种方式互斥：
1. h_local=ζv|v|/(2g)，ζ≥0。
2. h_total=(1+k_local)h_f，k_local≥0。

输入 ζ 和 k_local 同时非零被拒绝。沿程倍率输入的状态不会叠加另一个局阻。直接等效阻力：h=R Q|Q|，R 单位 s²/m⁵，R>0；不把参考截图中含混的单位直接照抄。

拆分：实际管长和 ζ 按拆分比例分摊，内径和粗糙度不变；沿程倍率保留到两段；等效 R 按比例分摊。因此串联总长度/阻力含义保持。图形移动和对齐不修改任何物理量。

## 4. 泵

基准曲线用升幂多项式 H₀(q)=a₀+a₁q+a₂q²+a₃q³，q 单位 m³/s，H 单位 m。系数单位 m/(m³/s)^i，最多三次。拟合是普通最小二乘；二次至少三个不重复点、三次至少四点，输出 RMSE 和有效流量范围。原说明书的四参数公式未明确，本实现不兼容其未知系数约定。

相对转速 n=N/N₀，同型同速并联台数 k：H(Q,n,k)=n²H₀(Q/(kn))。这是稳态相似定律，未考虑效率随转速变化、串联内部不均匀、并联异型泵抢水或关阀动态。异型泵可作为多条独立泵支路建模，不能把 k 理解为任意泵组的等效系数。n=0 按停泵隔离；本版本不建模停机泵的自由反流特性。

泵缺省含止回装置；超出声明的有效流量范围会警告外推。没有有效范围时用户必须自行复核，不自动保证曲线真实、单调或选型合理。示例泵均人工构造、非厂家数据。不能用恒扬程近似掩盖缺失的性能资料。

水力功率 P_h=ρg max(0,QH_pump)。只有用户提供整机效率 η 时才输出估算输入功率 P_in=P_h/η；否则为 null/“—”。不根据 Q、H 凭空生成整机效率。不计算年耗电量，除非后续有明确运行时间和效率数据。

## 5. 阀门

全开 Kv 定义：水在 1 bar 压差下的 m³/h。开度 u∈[0,1]。

线性：Kv(u)=Kv_max u；等百分比：Kv(u)=Kv_max R^(u−1)，R≥1。u=0 特别定义为完全关闭（不是 R 的最小漏流）。

h=[3600Q/Kv(u)]|3600Q/Kv(u)|·100000/(1000g)。这是按 Kv 的水密度标准定义换成水头；实际压差仍乘本工况 ρg。Cv 尚未实现独立输入，不自动猜测 Cv/Kv。全闭或手动 closed 从活动拓扑移除，关闭后仍保留两侧静压差，Q=0，不能用极大阻力近似替代。

## 6. 末端、流量调节器、止回

定阻末端：R=H_design/Q_design²，h=RQ|Q|。设计流量不是强制流量；不足 95% 设计值产生工况提示（默认 5% 容差是教学检查阈值，不是通用规范）。

理想流控：Q=Q_set 代替普通能量方程，控制器吸收可用压差。若其两端 H_source−H_target<最低资用差压，状态为 `demand_unsatisfied`，不能把方程里强制出来的 Q 当作可实现工况。不模拟控制器动态、饱和切换和真实厂家阀特性。

止回元件：a=Q/Q_scale≥0，b=(h_loss−(H_source−H_target))/H_scale≥0，ab=0。Fischer–Burmeister 方程 √(a²+b²)−a−b=0；开启时满足能量关系，关闭时允许反向压差。有限精度下检查负流量/互补残差，不偷偷截断用户物理输入。

## 7. 边界与数值

每个活动连通分量至少有一个真实定压参考。允许多个定压边界，分别输出边界流量；多个定压本身不等于冲突。已知直接恒扬程泵与两端规定水头差矛盾时报告 `boundary_conflict`；一般失败只报告残差失败，不泛称无解。

未知量：非定压节点 H 和活动支路 Q。质量/水头分别以流量尺度和水头尺度归一化。preview.3 首先用稀疏完整牛顿方向：守恒/水头项按结构求导、单支路损失用标量中心差分、止回用 Fischer–Burmeister 广义导数，行列均衡后用稀疏直接分解；回溯检查原始归一化残差的下降，不改物理方程或输入。差分步长仅估算导数，不作为最小流量或物理阻力。

局部雅可比奇异或回溯停滞时回退 SciPy `least_squares(method='trf')`；未知量不超过 128 时允许有界稠密分解，大模型保持稀疏 LSMR，不构建无界稠密零空间。默认总残差评估预算仍为 600，牛顿阶段最多使用 80 次（或总预算的一半），TRF 只使用剩余预算。结果 `iterations` 是残差评估计数，不是证明收敛的指标。退出原因、算法版本、输入 SHA-256 和计算时刻随结果保存。该局部方法不保证所有输入全局收敛或泵工作点唯一稳定。

独立验收：非定压质量残差≤10⁻⁸ m³/s，支路能量/互补残差≤10⁻⁵ m。优化器说“成功”不代表物理残差自动合格。30 s 内核默认超时，桌面子任务 45 s、外部 50 s 强制终止。非法模型、边界冲突、数值失败、控制需求不足分别报告。未实现全局无解证明。

## 8. 分析能力的准确分类

1. **稳态**：当前输入的守恒工作点。
2. **扫描**：笛卡尔积参数网格，每点重新求稳态，最多 1000 点，不携带时间状态。
3. **可及性**：固定工况需求检查，或在用户规定泵速/阀位上下界内进行多起点 Powell 局部可行性搜索。找到合格点可证明该点可行；未找到只报告 `undetermined`。不宣称全局不可行或全局最优。违规约束逐项给出对象、实际、要求和归一化违反量。
4. **敏感性**：用户指定步长的中心差分；需两侧工况均求解合格，不是导数的严格误差保证。
5. **时间状态控制/热动态**：尚未实现。稳态热混合/负荷输送也尚未实现。
6. **水锤/快速瞬态与三维 CFD**：不属于默认实现，当前没有这些能力。
7. **水力平衡（流量设定法，SPEC-002）**：
   - 配对：从末端出发，沿“只连两条支路、无需求、非定压”的直通节点向两侧延伸成串联链；链上恰有一个阀门才配对，并记录阀门相对末端流向的方向。
   - 所需压差：临时模型中把已配对阀门换成理想流控（Q = 末端设计流量，最低资用差压 0），在给定泵速下求解一次；流控两端水头差 Δh 即阀门需消耗的压头。Δh ≤ 0 表示该环路资用压头不足。
   - 反算：Kv_req = 3600·Q/√(Δh·1000g/10⁵)（与第 5 节 Kv 定义一致）；线性 u = Kv_req/Kv_max，等百分比 u = 1 + ln(Kv_req/Kv_max)/ln R。u > 1 为压头不足，等百分比 u ≤ 0 为阀门过大无法节流。
   - 最低泵速：泵速升高时各环路资用压头单调增加（本模型下的工程假设），对“全部 u ≤ 1”二分 30 次；向上取整到设定精度后在该泵速下重算其余阀门，最不利环路保持全开。
   - 验证：取整后的泵速与开度写回原模型正常求解，报告各末端实际流量与偏差；反算值不作为达到的流量。
   - 适用前提：每个需调节末端串联唯一平衡阀；未配对末端不受控，只如实报告。不推荐阀门口径，不模拟动态平衡阀、压差控制器或控制器动作，不计算电功率。

单线展开：仅对称供回水骨架；每条供水管创建参数相同、方向反转的回水管；源泵跨接源回/供节点，末端跨接对应供回节点；`mapping` 保留原对象与展开 ID 的一对多关系。含不明确单线漏补水或定压的骨架被拒绝，必须在双线模型明确指定。
