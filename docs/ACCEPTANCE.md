# 可重复流程验收脚本

这不是声称已经完成真实用户测试。

|步骤|动作|通过标准|
|---|---|---|
|1|首次启动 → 公开示例|画布显示双末端闭式循环，左结构/右属性/底结果可发现|
|2|点击 P2，内径改 0.05 m；点击 T2 复核设计值|字段显示单位、范围与解释，Enter/失焦提交；图形移动不改变长度|
|3|点击 PU1，相对转速改 0.8|泵曲线和并联参数可见；示例标注非厂家数据|
|4|检查 → 计算 → 问题列表|质量/能量残差合格；末端不足提示可定位，数值失败不伪称全局无解|
|5|计算前后各保存工况快照并比较|显示绝对值/差值/比例；基准为零时不虚构比例|
|6|保存、关闭/重开、重新计算|模型和布局完整往返，结果输入归属一致|
|7|CSV/PDF/SVG/PNG 导出|实际可读取文件；PDF 有输入、假设、算法版本、哈希和残差；过期结果禁止当当前结果导出|

自动化入口：`tests/ui.e2e.cjs`。目前实际覆盖步骤 1、2 的管径修改、3–6 和 CSV/PDF；末端参数编辑、全部图像格式导出、多平台字体和人工理解程度仍需扩展验收。图编辑纯命令测试不能替代全部真实鼠标操作。

原生 Windows 验收：运行便携包 `验证计算.cmd`、启动 `OpenHydroNet.exe`，执行上述步骤；检查退出后无遗留 Python 进程；中文路径保存/重开；100/125/150% 显示缩放；断网运行。未执行前不得打勾。
