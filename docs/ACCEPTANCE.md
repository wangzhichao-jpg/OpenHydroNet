# 可重复流程验收脚本

这不是声称已经完成真实用户测试。

|步骤|动作|通过标准|
|---|---|---|
|1|首次启动 → 公开示例|画布显示双末端闭式循环，左结构/右属性/底结果可发现|
|2|点击 P2，内径改 0.05 m；点击 T2 复核设计值|字段显示单位、范围与解释，Enter/失焦提交；图形移动不改变长度|
|3|点击 PU1，相对转速改 0.8|泵曲线和并联参数可见；示例标注非厂家数据|
|4|检查 → 计算 → 问题列表|质量/能量残差合格；末端不足提示可定位，数值失败不伪称全局无解|
|5|计算前后各保存工况快照并比较|显示绝对值/差值/比例；基准为零时不虚构比例|
|6|保存、关闭/重开、重新计算|模型和布局完整往返，结果输入归属一致|
|7|CSV/PDF/SVG/PNG 导出|实际可读取文件；PDF 有输入、假设、算法版本、哈希和残差；过期结果禁止当当前结果导出|

preview.2 的 Linux 真实自动化入口包括 `ui.e2e.cjs`、`ui.graph.cjs`、`ui.lifecycle.cjs`、`ui.features.cjs`、`ui.jobs.cjs`。已测上述基础闭环、真实端口拖拽、PNG/SVG、跨温度比较、库/CSV/XLSX、原生退出与迟到任务；仍需更多设备组合、多平台字体和人工理解测试，不能用纯命令测试替代鼠标操作。

新增验收：
- 20 ℃先算/存工况，再改 80 ℃重算，选 kg/h；比较两份结果应分别用各自密度，不能把体积不变错误解释为质量不变。0 ℃参数编辑也是有效输入。
- 并联台数输入 1.5 后检查/计算/保存不得使用旧值冒充新输入；Esc 放弃字段；原生关闭应提交有效值或阻止无效值，取消保存/退出后计算服务仍可用。
- 导入人工库、拟合点、查看来源/范围、应用到 PU1；保留 ID/连接/泵速。删除库条目后工程仍能算；阀库应用保留开度。
- 导入 parameter-update.csv，明确 mm 映射，预览 P2/P3 的 SI 变化并一次应用/撤销；非法 ID/单位/整数不能部分应用。实际导出 XLSX 再选支路表重导入，确认无意外变化。
- 启动坏结构草稿不白屏，原字节备份可定位；切换工程后迟到的旧计算不附着，保存文件无过期结果标签。

原生 Windows 验收：运行便携包 `验证计算.cmd`、启动 `OpenHydroNet.exe`，执行上述步骤；检查退出后无遗留 Python 进程；中文路径保存/重开；100/125/150% 显示缩放；断网运行。未执行前不得打勾。
