# 设备库、曲线与 CSV / Excel 参数表

适用版本：`0.1.0-preview.2`。这是本地离线工作流，不访问厂家网站，不认证用户提供的数据，也不等于已有完整厂家目录。

## 1. 设备库管理

右侧“设备库 / 泵曲线”或底部“设备库 / 曲线”进入非模态工作区。可新增、改名、复制、删除泵/阀条目，选择数据类别并记录来源、页码、链接或测量条件。初始值全部明确标为**虚构教学数据**，不得直接用于真实选型。

- 选中画布/工程结构中的同类型设备，再点击“应用到同类选中设备”。不忽略混合类型选择，也不重写设备 ID、名称、端点、泵速/并联台数、阀开度或关闭状态。
- 应用的是参数及来源的**副本**。删除库条目不会使已建工程失效；来源、原参数和拟合点随工程设备保存。
- 新条目未提供效率时会清除设备原来的效率，而不是沿用另一台设备的假设。无有效效率不估算输入电功率。
- 手工改变应用后的曲线、Kv、效率或额定转速，会标记来源存在手工覆盖；原始参考值仍保留以便复核。
- 完整工程保存包含整个库。单独“导出库 JSON”生成 `format="openhydronet-library"`、`schema_version=1`；导入明确**作为副本**生成新库 ID，不覆盖已有条目。每工程最多 500 项。未补齐名称/来源的草稿可随工程保存，但不能作为完整库条目导出/应用。

## 2. 泵曲线拟合

输入每行一对 `流量,扬程`，不含表头。扬程用 m；流量可选 m³/h、kg/h、t/h、L/s。二次拟合至少三点，三次拟合至少四点，最多 100 点；流量不能重复，性能点须为非负有限数。

模型公开定义为单泵基准曲线：

```text
H0(Q) = a0 + a1 Q + a2 Q² (+ a3 Q³)，Q 为 m³/s，H 为 m
H(Q,n,k) = n² H0(Q/(k n))
```

这不是对参考软件未公开四参数公式的推测。`n` 是相对转速，`k` 是同型同速并联台数。声明基准额定转速后可输入实际 rpm，其换算为 `n=实际rpm/基准rpm`；修改基准 rpm 不自动重算曲线，必须确认系数也对应该基准。

质量流量点使用**点数据水温**对应的密度转换，初始取当前工程温度，之后不会自动跟随工程工况改变。图中圆点为上次拟合输入，曲线为当前系数；RMSE、有效范围、点温度/密度、原始点均保留。系数显示拟合原始精度，不偷偷清零小系数或改写原始点。

改变点草稿、单位、温度或阶数后，先重新拟合，或明确选择保留现有系数；不能把旧曲线冒充新数据。失败不会覆盖旧系数。异步返回时条目、参数或工程已改变会丢弃过期返回。正斜率/负拟合段会提示复核，不保证工作点唯一、稳定或全局可行。

当前通过点文本/系数编辑和曲线显示，不支持直接在图上拖点。尚无效率随流量/转速变化的曲面拟合，也没有厂家数据认证、黏度修正或 NPSH 认证。

## 3. 阀门库

记录全开 Kv、线性/等百分比特性、可调比。Kv 约定为参考水密度 1000 kg/m³、1 bar 压差下的 m³/h，实际水头损失按公开公式计算，不把 Kv 当作普通流量字段进行质量单位换算。

```text
Kv有效 = Kv全开 × u                   线性
Kv有效 = Kv全开 × R^(u−1)             等百分比
ΔH = (3600Q/Kv有效) × |3600Q/Kv有效| × 100000/(1000g)
```

`u=0` 或明确关闭按隔离拓扑处理，不用虚构小流量或极大阻力伪装关闭。应用库数据保留具体工程的开度；未知厂家固有特性不能据此视作已经还原。

## 4. CSV / XLSX 映射导入

1. 先在画布建好网络，或打开已有工程。右侧选择“导入参数表”。
2. 选择 CSV/XLSX；CSV 支持显式 UTF-8/GB18030 和逗号/分号/制表符；XLSX 可选择工作表，即使首张工作表不是数据表也可切换。
3. 选择节点、管段、泵、阀、末端、直接阻力或理想流控的类别。
4. 映射**已有稳定 ID**列，以及需要更新的参数列；逐字段确认输入单位。不需要修改的字段选“不导入”。只按明确字段名/单位表头预选映射，不根据 DN 猜内径。
5. “转换单位并预览变化”：显示原始表格、SI 前后值、对象 ID、转换温度/密度及全部输入/模型问题。
6. 无错误且有实际变化时，确认应用，一次提交并可整体撤销。预览后工程改变则拒绝覆盖，须重新预览。

本版是**现有设备参数更新**，不是从表格自动创建网络或猜测连接。不存在的 ID、重复 ID、不同设备类型、非整数并联台数、公式/非数值、未知单位和非法模型都会阻止应用，不部分写入、不替用户修正输入。空白默认保留原值；节点定压列有明确选项可将空白清除为非定压点。

- 内径/粗糙度支持 m、mm；流量支持 SI 和显示单位。质量输入按当时密度换为 SI 体积量；之后改变水温不会自动维持原质量设计量或热负荷。
- 末端设计压降可按当前工程密度进行 Pa/kPa→m 转换。
- 节点边界 `head` **仅接受测压水头 m**，不是表压 Pa，不忽略标高做错误换算。
- 泵系数通过设备库编辑/拟合；局阻模式、设备类型和端点不由参数表自动切换。
- Excel ID 列请用文本；已被 Excel 丢失的前导零无法恢复。数值不猜测千位/小数分隔符。
- 文件最大 3 MB、10000 行、256 列；XLSX 解压体积/成员数受限。不支持旧 XLS 或宏工作簿，不执行公式、不跟随外部工作簿链接；数值列中的公式会被拒绝。
- 大批变化当前只展示前 150 项；建议分批逐项审核。完整网络和工况仍以工程 JSON 为准。

## 5. 实际 Excel 导出

“参数 Excel”无需已有结果，导出按设备分表的已存参数及单位；空白表示该字段未显式存储，不能把它理解为完整工程重建格式。“结果 Excel”要求当前结果不处于过期状态，包含参数、支路/节点结果、算法/版本/输入哈希、物性/假设/残差等信息。

用户文本的表格公式前缀会转义。XLSX 是真实工作簿，不是把 CSV 改后缀。工程拓扑、完整曲线、来源与工况仍应使用 `.ohn.json` 保存；表格不替代完整工程。
