# 公开路线图

## A：端到端可信基础产品

已有可运行纵向切片：模板 → 参数 → 检查 → 求解 → 结果/水压图 → 工程保存重开 → CSV/PDF。

preview.2 已补退出保存/放弃/取消、损坏草稿/字节备份、存储故障注入、跨温度和异步归属。待补 Windows 原生完整流程、高 DPI、真实崩溃/断电和更完整画布/长期验收。A 不因首个切片通过而自动完成。

## B：参考功能完整覆盖

- 单线编辑/双线展开 UI、供回水映射和筛选。
- 多泵多源、不同供回水结构的公开示例和独立验证。
- 基础库、点编辑/拟合/残差/范围已在 preview.2 接通；继续补真实有许可数据、效率曲面和更丰富曲线交互。
- 子网、注释、热源边界的明确语义。
- 水力可及性工作流、约束编辑和最不利末端建议。
- 现有 ID 的 CSV/XLSX 映射预览、撤销和真实 XLSX 已在 preview.2 接通；继续补整网创建导入、完整参数文档与打印设置。
- 完善离线帮助、模板和可发现操作路径。

## C：可验证的超越能力

- 泵速/阀位/末端负荷稳态扫描的图形界面与批处理取消。
- 可解释敏感性、流量平衡辅助和受约束局部优化；明确无全局保证。
- 有效率/运行时长数据的能耗分析，区分水力功率、估算电功率和耗电量。
- 稳态温度混合/热输送，与温度相关物性耦合的验证。
- 明确定义热容、执行器状态、控制器和积分步长的时间模拟，与重复稳态扫描分开。
- 可扩展 API、回归数据集和外部独立工具交叉验证。

水锤与三维 CFD 非默认交付；不借此宣称拥有这些能力。
