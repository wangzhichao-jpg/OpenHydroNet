## 完成记录（2026-10-26）
- 偏离：由“一个参数 × 多观测量”扩展为“所选调节量 × 观测量矩阵”，因为用户故事 2 需要比较不同调节量；代价仅 1+2n 次求解。SPEC-001 已同步。
- 内核 `sensitivity_matrix`：中心差分，越过物理上下限时改单侧（`forward`/`backward`）；弹性在 Y 或 X 为 0 时为 None（不报 0 或无穷）；任一差分点不收敛为 `undetermined`。旧 `sensitivity()` 不存在 ID 改为中文 ValueError。
- 公开示例：T2 对泵速弹性约 1.03；两阀全开时弹性仅约 0.01–0.02（几乎调不动），V1 开大分走 T2 流量故为负。
- 界面：`SensitivityView.tsx` 与共享 `ObservablePicker.tsx`（扫描页同步改用）；每个观测量一句“影响最大：…”结论，表格加粗最强一格，悬停显示差分方式。
