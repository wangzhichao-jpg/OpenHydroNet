# T-009：可及性结果改进：最小调整与可设定精度

规范：[SPEC-001](../specs/SPEC-001-analysis-ui.md) · blocked_by：T-007 · 来源：T-007 审查

## 问题（实测）
- 局部搜索只保证找到“满足约束的点”，不保证调整最小。公开示例中 T2 流量近似与泵速成正比，满足 14.4 m³/h 只需泵速约 1.051（摩阻随雷诺数变化，非严格正比），但搜索返回约 1.135（T2 15.57 m³/h）。
- 返回值为原始浮点（如 1.1347524157501472），现场无法按此精度设定。

## 用户决定（2026-10-26）：两项都做（SPEC-001 D7、D8）

原待定项：
- 是否增加“在满足约束的前提下尽量少调整”的目标（如相对当前值的偏差平方和最小），仍为局部搜索、不做全局保证。
- 调节值是否按设定精度（如泵速 0.01、阀开度 0.01）取整后重新验算，取整后不满足时如实报告。

## 验收
- 公开示例：泵速单变量搜索给出约 1.05–1.06；取整后的值重新计算仍满足全部约束，或明确提示不满足。

## 完成记录（2026-10-26）
- 内核：可行性搜索后 `_pull_back`（当前值↔可行点连线二分，再逐坐标二分收回，每个接受点均重新求解验证），再 `_round_to_steps`（先最近取整，不满足再向远离当前值方向取整，限定在上下界内；都不满足报告 `rounded_infeasible` 并保留未取整值）。共用 800 次评估预算；预算耗尽时返回已验证的可行点。桌面请求默认精度 0.01，直接调用内核 API 不取整（原行为不变）。
- 结果：公开示例 首个可行 1.135 → 尽量少调整 1.051 → 取整 1.06（1.05 不满足），两阀不变；额外 34 次求解，总 0.47 s。
- 订正：此前所说“只需约 1.053”不准确；Haaland 摩阻随雷诺数变化，流量与泵速非严格正比，门槛约 1.0514。
- 界面：每个调节量增加“设定精度”；结果显示三步过程说明，标题与“建议值”列。
- 测试：pytest `tests/test_accessibility_refine.py` 11 项（含取整不满足、已可行无需调整、预算不足、旧 API 不取整、精度校验）；tsx 新增 1 项并更新 2 项；E2E 断言建议值 1.06、过程说明与应用后 1.06。
- 两路审查：规范——过程说明只计算一次；对照规范——无缺口（界面修改设定精度仅单元测试覆盖）。
