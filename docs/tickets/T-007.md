# T-007：可行点保存为工况 / 应用到工程

规范：[SPEC-001](../specs/SPEC-001-analysis-ui.md) · blocked_by：T-006

## 范围
- “保存为工况快照”：以可行点模型 + 结果新建 scenario，不改当前模型，跳到工况对比。
- “应用到当前工程”：写入调节值，进入撤销历史；结果过期则两按钮禁用。

## 验收（均需自动测试）
- E2E：保存后工况对比多一项；应用后 PU1 速度改变，撤销恢复原值。

## 完成记录（2026-10-26）
- `applyAdjustments`（只改泵速/阀开度）、`adjustmentSummary`；`AnalysisPanel` 提供 `AnalysisActions` 回调，写入工程统一走 `App` 的撤销历史与无效输入检查。
- 保存工况：模型 = 搜索冻结模型 + 调节值，结果 = 内核对该点的完整结果，二者严格对应；自动选为对比基准。
- 应用：写入当前模型；若当前模型恰为找到的点，显示“已应用”（不算过期，按钮禁用），撤销后自动恢复；其他编辑使结果过期，两按钮禁用。
- 测试：tsx 新增 2 项；E2E 覆盖保存不改工程、应用/已应用状态/撤销、过期禁用、对比页中方案与重新计算结果逐支路一致（差值 0）。
- 审查发现规范未预料的问题：应用后被误判为过期且状态栏提示被过期提示覆盖 → 改为由模型推导“已应用”状态，在分析页内提示。
