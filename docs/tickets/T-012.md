# T-012：水力平衡子页：设置与结果

规范：[SPEC-002](../specs/SPEC-002-hydraulic-balancing.md) · blocked_by：T-011

## 范围
- 分析页新增“水力平衡”子页：选择调速泵或“泵速固定”，泵速上下界，设定精度，验证容差；配对预览（哪些末端有阀、哪些无阀/多阀）。
- 结果：结论、最不利环路、每个平衡阀的建议开度与验证流量（偏差超容差标红）、平衡前后对比（泵速、扬程、流量、水力功率）、小开度提示。

## 验收（均需自动测试）
- tsx：请求组装、配对预览、结果行换算与前后对比。
- E2E：两种模式在公开示例上的结论、开度、最不利环路、位置断言。
