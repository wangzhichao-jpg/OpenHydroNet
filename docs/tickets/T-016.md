# T-016：W4-07 中文对话框标题与 OpenHydroNet 窗口图标

## 范围
- 运行期对话框（计算进程退出、退出已取消）由 `showErrorBox`（Windows 标题为 “Error”）改为带中文标题的 `showMessageBox`。
- 新增应用图标（PNG/ICO），主窗口、启动窗口使用；EXE 文件本身的资源图标不改（需 Windows 资源编辑工具），写入已知限制。

## 验收
- E2E：主窗口与启动窗口的图标路径存在且被设置；源码中不再使用 `showErrorBox`。
