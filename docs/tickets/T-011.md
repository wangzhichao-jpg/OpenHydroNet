# T-011：水力平衡内核：配对、流量设定法、最低泵速、取整验证

规范：[SPEC-002](../specs/SPEC-002-hydraulic-balancing.md) · blocked_by：—

## 范围
- `balancing.py`：`pair_balancing_valves`（串联链识别：配对 / 无阀 / 多阀，考虑阀门方向）、`required_openings(model, speed)`（理想流控替换后求解，反算 Kv 与开度，线性/等百分比）、`balance(model, ...)`（泵速可调时二分最低泵速；固定泵速只算阀门；取整后写回原模型验证）。
- `analysis.check_request` 新增 kind `balance`，`run_request` 分派；进度按求解次数上报；分析任务可用。
- 结果：每个配对（末端、阀、设计流量、所需压差、所需 Kv、精确/取整开度、验证流量、偏差、提示），最不利环路，泵速前后，泵扬程/流量/水力功率前后，未配对末端及其验证流量。

## 验收（均需自动测试）
- 公开示例两种模式数值（见 SPEC-002 完成标准）；验证流量偏差在容差内。
- 解析小网：单末端单阀，所需开度与手算 Kv 一致；等百分比反算往返。
- 无阀末端、多阀串联、阀门方向相反、泵速上限不足、等百分比阀过大、请求校验均有中文信息。

## 完成记录（2026-10-26）
- `balancing.py`：串联链配对（直通节点：两条支路、无需求、非定压；记录阀门方向，反向时临时流控随之翻转，因 set_flow 须为正）；理想流控求所需压差 → Kv → 开度（线性/等百分比）；泵速参与时二分 30 次求最低泵速，泵速向上取整后在新泵速下重算其余阀门，最不利环路保持全开；仅二分到边界时才认定最不利环路（停在下限时各阀均有余量）。取整后真实求解验证。
- 请求 kind `balance`（`_check_balance`/`_run_balance`），后台任务进度总数 35（固定泵速 3）。
- 公开示例：泵速参与 → T2 为最不利环路，0.975→0.98，V1 0.22，偏差 −0.84%/+1.01%，泵水力功率 1568→1504 W；泵速固定 → V1 0.20、V2 0.40，水力功率反而 +2.3%（关阀使扬程升高），节能来自降速。
- 测试：`tests/test_balancing.py` 19 项（含手算小网 开度 0.5 与最低泵速 √0.625、等百分比反算往返、无阀/多阀/反向阀、泵不足/阀过大/小开度、请求校验、不修改输入、后台任务）。
- 测试订正：V1 期望值由 0.23 改为 0.22（取整后泵速下重算，属设计行为）；“无阀末端”用例改为泵速参与，因定速时 T2 确实差 1.96 m。
