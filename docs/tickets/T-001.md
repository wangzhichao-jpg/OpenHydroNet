# T-001：单参数扫描端到端（任务通道 + 分析页 + 结果表）

规范：[SPEC-001](../specs/SPEC-001-analysis-ui.md) · blocked_by：—

## 范围
- 内核 `analysis.run_request(request, progress)`：校验 kind/字段/ID；扫描只允许泵 `speed`、阀 `opening`；观测量引用失效报中文错误。
- 扫描结果精简：每点 `changes`、`status`、`values`（观测量，SI）、`issues`（`{code, object_id}`，界面显示中文简述与对象名）；不含整网结果。
- `cli analyze -`：stdin 读请求，stdout 输出结果，stderr 逐行 `{"progress":{"done","total"}}`。
- `/api/analysis-jobs` POST/GET/DELETE；GET 返回进度；300 s 超时；与计算任务合计最多 2 个运行中；取消后进程确认停止。
- 界面“分析”页 → 扫描子页：选泵/阀与参数、起点/终点/点数（≤1000）、观测量默认全部末端流量；运行、进度、取消；结果表格按当前流量单位显示。
- 冻结快照：运行后编辑模型 → 结果显示“过期”横幅。

## 验收（均需自动测试）
- pytest：精简结果字段、非法字段/ID/点数被拒、进度回调次数 = 点数、CLI 进度行、服务端取消/超时/并发上限。
- tsx 单元：取值生成（端点含、点数界限）、请求组装、SI→显示单位。
- E2E（tests/ui.analysis.cjs）：公开示例，PU1 speed 0.6–1.4 共 5 点，表格 5 行且 T2 流量单调递增；编辑参数后出现过期横幅。
