# T-018：W4-01 撤销回到已计算模型后状态栏仍显示“过期”

来源：[preview.4 Windows 验收](../../validation/windows/0.1.0-preview.4/验收记录.md) · blocked_by：—

## 范围
- 结果从过期恢复为有效时，状态栏改为与当前结果一致的文字（如“计算通过；已回到计算时的输入”）。

## 验收
- E2E：计算 → 改泵速 → Ctrl+Z → 状态栏不含“过期”，徽标为计算通过。

## 完成记录（2026-10-27）
- `App.tsx`：过期结束时，若结果对象未变（撤销/重做回到计算时的输入），状态栏改为“<状态>；已回到计算时的输入，结果有效”；新计算结束过期时保留计算自身的提示。
- E2E（`ui.e2e.cjs`）：计算 → 泵速 0.9 → 状态栏“旧结果过期” → 撤销 → 徽标计算通过、状态栏不含“过期”、结果 CSV 可用。修复前失败。
