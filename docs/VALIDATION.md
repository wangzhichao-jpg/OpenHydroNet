## 2. 预先定义的数值门槛

- 非定压节点最大绝对质量残差 ≤ 1e-8 m³/s。
- 支路最大能量/止回互补残差 ≤ 1e-5 m。
- 二次阻力串并联和泵交点解析解相对流量误差通常 ≤ 1e-5（各测试有明确值）。
- 层流管 Poiseuille 独立式相对流量误差 ≤ 2e-5。
- Haaland 生产近似与独立 Colebrook 迭代的流量差允许 ≤ 1.5%；这是摩阻近似差，不通过给同一实现换名字自证。
- 对称环网的桥接支路流量绝对误差 ≤ 1e-8 m³/s。
- 温度物性使用经验近似，20 ℃密度约 998.2 kg/m³，相对误差门槛 0.1%；运动黏度约 1.004e-6 m²/s，相对门槛 1.5%。
- 公开网格解析水头最大绝对误差 ≤ 1e-4 m。

验收在测试代码中明确；没有因为失败放松误差。初版发现 SciPy LSMR 一维信赖域子空间异常，改用小模型稠密分解；零压差/零流量工况使用物理一致初值，不引入最小虚构流量。

## 5. 公开性能基准（单次实测，不是性能上限）

机器：AMD Ryzen 7 8845HS，8 核/16 线程；OpenBLAS/OMP 线程限 1。每个规模在独立 Python 进程运行，RSS 包含解释器与科学计算库；耗时从模型构建后到求解和残差检查结束，不含进程启动和 UI 绘制。原始记录 `artifacts/benchmark.json`。

模型：二维等径管网，左右边界分别 H=50/30 m，无节点耗水，上下无外边界。由于对称性，预先已知每一行 H 随列线性变化，纵向支路为零流量。生成器 `tools/benchmark.py`，工程在 `examples/benchmarks/`。

|级别|节点/支路|实测耗时 s|峰值 RSS MiB|质量残差 m³/s|能量残差 m|独立水头最大误差 m|
|---|---|---|---|---|---|---|
|小 5×5|25/40|0.038|76.80|8.01e-16|1.14e-8|1.79e-8|
|中 10×10|100/180|0.295|77.49|6.88e-16|2.02e-8|5.63e-8|
|大 20×20|400/760|1.110|79.11|9.70e-16|3.78e-8|1.41e-7|

全部本次基准通过，但不推广为任意 400 节点复杂泵阀系统一定能在同样时间收敛，更不宣称无限规模或毫秒级交互。尚未给出重复测量置信区间和 Windows 性能结果。
