# SPEC-002：水力平衡辅助

状态：进行中（2026-10-26） · 覆盖矩阵：H14（相关）、X02（流量平衡辅助） · 任务卡：T-011～T-014

## 背景
末端只靠泵速保证最不利末端时，近端会超流、泵功耗偏高。公开示例平衡前 T1 超流 22%、T2 欠流 5%；可及性搜索只能把泵速提高到 1.06。水力平衡先把各末端的平衡阀整定到设计流量，再取能满足最不利环路的最低泵速：原型中泵速降到 0.975，泵水力功率降低约 5.6%，两个末端都精确等于设计流量。

## 用户故事
调试/设计人员：“给出每个平衡阀的开度和泵速，使每个末端达到设计流量，并告诉我最不利环路是哪一路、比现在省多少。”

## 方法：流量设定法（确定性计算，非搜索）
1. **配对**：每个有设计流量的末端，沿串联链（经过只连两条支路、无需求、非定压的节点）找平衡阀。恰好 1 个 → 配对；0 个 → 无法单独调节；多于 1 个 → 不自动选择，提示用户。
2. **所需压差**：临时模型中把已配对的阀门换成理想流控（流量 = 末端设计流量），在给定泵速下求解一次；流控两端的水头差即该阀必须消耗的压差 Δh。
3. **反算开度**：Kv_req = 3600·Q / √(Δh·1000g/10⁵)；线性 u = Kv_req/Kv_max，等百分比 u = 1 + ln(Kv_req/Kv_max)/ln R。
4. **最低泵速**（泵速参与时）：泵速越高各支路资用压差越大；二分求使所有开度 ≤ 1 的最低泵速。此时开度为 1 的一路为**最不利环路**。
5. **取整与验证**：开度、泵速按设定精度（默认 0.01，泵速向上取整）取整，写回原模型正常求解，逐末端报告流量与设计值偏差。验证由真实求解完成，不由反算结果代替。

## 默认决策（D1～D4 待用户确认；D5 起沿用 SPEC-001 惯例）
| # | 问题 | 默认 | 理由 |
|---|---|---|---|
| D1 | 目标 | 各已配对末端 = 设计流量；泵速可调时取满足的最低泵速（最不利环路阀门全开）；可切换为“泵速固定，只调阀门” | 标准平衡做法；定速泵也能用 |
| D2 | 没有串联平衡阀的末端 | 照常计算其余末端，并列出这些末端平衡后的实际流量与偏差 | 不因个别末端阻止整体平衡；如实报告 |
| D3 | 取整后验证容差 | 流量偏差 ±5%（可修改；与现有“不足 95% 设计值”提示一致，属教学阈值，不引用规范条文） | 与现有诊断一致 |
| D4 | 小开度提示 | 开度 < 0.2 提示“阀门口径可能偏大，调节性能差”；等百分比阀无法节流到所需 Kv 时报告为无法平衡 | 小开度调节灵敏、易受误差影响 |
| D5 | 结果落地 | 与可及性一致：保存为工况快照 / 应用到当前工程（可撤销） | 复用 T-007 |
| D6 | 多台泵 | 用户选择一台参与调速的泵；其余泵保持原转速 | 避免隐含的并联调速规则 |

## 不做
- 自动选型（推荐阀门口径/Kv）、动态平衡阀/压差控制器建模、多泵联合调速策略、能耗（电功率）计算、环网中无配对末端的流量保证。
- 不宣称结果满足某一标准条文。

## 完成标准
- 公开示例：泵速参与（0.5–1.5）→ 最不利环路 T2，最低泵速约 0.975、向上取整为 0.98，V1 在 0.98 下重算并取整为 0.22，V2 = 1；验证后两末端偏差均在 ±5% 内；泵水力功率低于平衡前。
- 泵速固定 1.0：只调阀，V1、V2 开度分别约 0.20、0.40，两末端达标。
- 无平衡阀末端、多阀串联、泵速上限内无法满足、等百分比阀过大等情况均有中文提示与测试。
