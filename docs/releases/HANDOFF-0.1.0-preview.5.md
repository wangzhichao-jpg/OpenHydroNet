## 对 PC 驱动脚本的影响（必读）
- 启动时可能先出现**启动窗口**（`desktop/startup.html`，后端 0.7 s 内未就绪才显示）。`app.firstWindow()` 可能返回它，而不是工作台。请按地址找主窗口：URL 以 `http://127.0.0.1:` 开头（可参考 `tests/e2e-util.cjs` 的 `mainWindow(app)`）；启动窗口 URL 以 `/startup.html` 结尾。
- 启动窗口元素：`#message`（状态/失败原因）、`#hint`（说明）、`#elapsed`（已等待秒数）、`#detail`（运行时路径与错误输出）、按钮 `#retry`“重试”、`#quit`“退出”。
- 环境变量 `OHN_BACKEND_TIMEOUT_MS` 可临时缩短时限（仅诊断/测试用，默认 120000）。
- `validation/windows/0.1.0-preview.4/lib.cjs` 的路径与版本由 PC 自行调整。
