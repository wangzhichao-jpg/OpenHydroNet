# OpenHydroNet 0.1.0-preview.5 — 分析工作区、水力平衡与 Windows 首次启动修复

开发预览版，未代码签名，不是认证工程软件。结果须经工程人员复核后使用。preview.4 经 Windows 实机验收发现首次启动问题，未公开发布；它的全部新功能首次随本版本发布。

## 新功能（来自 preview.4）
底部“分析”页，四个子页（均为稳态计算，不是时间动态；在运行时冻结的模型副本上进行，可取消）：
- **参数扫描**：泵速/阀开度，1–2 个参数（≤1000 点）；曲线、表格、CSV 导出。
- **敏感性**：调节量 × 观测量的弹性系数与导数，指出影响最大的调节量。
- **可及性**：约束编辑与当前工作点检查；有界局部搜索 → 尽量少调整 → 按设定精度取整并重新验算。“未确定”不代表无解。
- **水力平衡**：流量设定法反算平衡阀开度；变频时求最低泵速与最不利环路；取整后真实计算验证；平衡前后泵扬程、流量、水力功率对比。
- 可及性与平衡结果可“保存为工况快照”或“应用到当前工程”（一次撤销恢复）。

公开示例：水力平衡后泵速 1 → 0.98，调节阀 1 开度 0.22、调节阀 2 全开，两末端偏差约 ±1%，泵水力功率约 −4%。

## 本版修复（来自 preview.4 Windows 验收）
- **首次启动**：刚解压后第一次启动时，杀毒软件扫描新文件可能使计算内核需要几十秒。现在显示启动窗口与已等待秒数，最长等待 120 秒；失败时说明原因并可“重试”。
- 撤销回到已计算输入后状态栏文字、功率显示精度、PDF“假设和验证”可读性、分析页运行按钮可见性、中文对话框标题与窗口图标。
- `开始使用.txt` 与用户手册说明“未知发布者”提示与 SHA-256 核对方法。

## 使用前
1. 核对 SHA-256：`Get-FileHash .\OpenHydroNet-0.1.0-preview.5-win-x64.zip -Algorithm SHA256`，应与附件 `.sha256` 一致。
2. 出现“未知发布者 / Windows 已保护你的电脑”是未签名程序的正常提示；核对一致后再选择运行，不要关闭 SmartScreen 或杀毒软件。
3. 解压后先运行 `验证计算.cmd`。

## 兼容性与验证
- 求解内核算法、工程文件格式（schema v1）、依赖版本均与 preview.3 相同；preview.3 工程可直接打开。
- Linux：Python 182 项、TS 单元 52 项、Node 单元 22 项、7 套真实 Electron 流程；GitHub CI 在 Ubuntu 与 Windows 上运行全部测试。Windows 便携包由 CI 在 Windows 上组装，随包 Python 实际求解公开示例，并通过结构/隐私审计。
