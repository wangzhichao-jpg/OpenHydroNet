# OpenHydroNet 0.1.0-preview.4 — 分析工作区与水力平衡

开发预览版，未代码签名，不是认证工程软件。结果须经工程人员复核后使用。

## 新功能
底部新增“分析”页，四个子页（均为稳态计算，不是时间动态；在运行时冻结的模型副本上进行，可取消）：

- **参数扫描**：泵速/阀开度，1–2 个参数（≤1000 点）；曲线（失败点断线、不插值）、表格、CSV 导出。
- **敏感性**：调节量 × 观测量矩阵，弹性系数与导数，指出影响最大的调节量；物理上下限处自动单侧差分。
- **可及性**：约束编辑（默认末端设计流量）、当前工作点检查；有界局部搜索 → 尽量少调整 → 按设定精度取整并重新验算。结论只有“满足 / 不满足 / 找到可行点 / 未确定”，“未确定”不代表无解。
- **水力平衡**：流量设定法反算各平衡阀开度；变频时求最低泵速与最不利环路；取整后真实计算验证（默认 ±5%，教学阈值）；平衡前后泵扬程、流量、水力功率对比。
- 可及性与平衡结果可“保存为工况快照”或“应用到当前工程”（一次撤销恢复）。

公开示例：T2 原为 13.68 m³/h（设计 14.4）。水力平衡后泵速 1 → 0.98，调节阀 1 开度 0.22、调节阀 2 全开，两末端偏差约 ±1%，泵水力功率约 −4%。

## 兼容性与依赖
- 求解内核算法、工程文件格式（schema v1）未变；preview.3 工程可直接打开。分析设置不写入工程文件。
- 依赖版本与 preview.3 相同（Electron 44.9.1、Python 3.12.10、NumPy 2.4.3、SciPy 1.17.1、openpyxl 3.1.5）；2026-10-27 npm audit、pip-audit 均无已知漏洞。

## 验证范围
- Linux：Python 180 项、前端与 Node 单元 63 项（TS 52 + Node 11）、6 套真实 Electron 流程。GitHub CI：同一提交在 Ubuntu 与 Windows Server 上运行全部测试（含真实 Electron）。
- Windows 便携包由标签触发的 CI 在 Windows 上组装，随包 Python 实际求解公开示例，并通过结构/隐私审计。**新版 Windows 真机人工验收尚未完成。**
- 详见 `docs/VALIDATION.md`、`docs/KNOWN_LIMITATIONS.md`、用户手册第 6 章。

# OpenHydroNet 0.1.0-preview.4 — Analysis workspace and hydraulic balancing

Development preview, unsigned, not certified engineering software.

- New **Analysis** panel: 1–2 parameter steady sweeps with charts and CSV; sensitivity matrix (elasticities); hydraulic accessibility (constraints, bounded local search with least adjustment and settable-precision rounding, re-verified); **hydraulic balancing** by the designated-flow method (valve openings, lowest pump speed, index circuit, verified by a real solve, before/after pump comparison). Results can be saved as scenarios or applied (one undo step).
- Solver algorithm and project format (schema v1) unchanged; dependencies unchanged from preview.3, no known vulnerabilities (npm audit, pip-audit, 2026-10-27).
- Tested on Linux (180 Python, 63 front-end/Node unit tests, 6 real Electron suites) and in CI on Ubuntu and Windows. The Windows portable build is assembled by tag-triggered CI on Windows with a bundled-runtime smoke solve; manual Windows acceptance of this version is still pending.
