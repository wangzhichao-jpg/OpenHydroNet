## 物理和数值边界

- 全网单温纯水 0–100 ℃；无防冻液、加压高温物性或热力耦合。0 ℃输入/换算已回归验证，不能据此扩大物性适用范围。
- Haaland 是 Colebrook 的近似；过渡区为公开的平滑工程约定。集中节点不显式求速度水头，变截面需工程等效损失。
- 停泵按隔离处理；缺省泵含止回；并联只等价同型同速。相对转速允许 0–2，并联台数为 1–20 整数，这是当前产品输入范围，不代表真实设备允许范围。
- 曲线可外推到负扬程；不会伪造厂家曲线、自动清零小系数或修正不利数据。已给出的有效范围/正斜率警告须复核，拟合成功不保证工作点唯一稳定。
- 只有用户提供的常数整机效率，没有效率曲面、NPSH/厂家认证；缺效率不估算输入功率。
- 理想流控没有完整饱和切换，强制流量后若压差不足，不作为有效工作点。局部不收敛不证明全局无解。
- preview.2 的私有高阻比失败已在 preview.3 修复，并与独立守恒环流解相符；新增不取自论文的高阻比/反流/小流量/稀疏/正耗水回归。局部牛顿/TRF 仍不保证任意极端输入全局收敛；预算失败仍报告 numerical_failure，不是无解证明。阻力反算不验证真实摩阻、绝压、高温物性或现场精度，私有原网络未公开。
- 仅在直接矛盾的恒扬程泵/固定边界时给出边界冲突证明；一般问题不自动证明全部物理不可行原因。
- 仅单相汽化风险筛查，不代替 NPSH 或安全认证。可及性为有界局部搜索，无全局最优/不可行保证。
- 扫描是独立稳态，不是时间动态、水锤或 CFD。

## 分析（扫描、敏感性、可及性）

- 可调参数仅泵相对转速和阀开度；不扫描/搜索管径、设计流量等设计参数。扫描单批 ≤1000 点，分析单次 ≤300 s，可及性搜索 ≤800 次计算。
- 可及性搜索为有界局部搜索：“未确定”不能证明无解；“尽量少调整”是局部改进，不保证调整最小；结果依赖起点和上下界。
- 设定精度取整后会重新验算；不满足时保留未取整值，现场仍需按实际可设定值复核。
- 敏感性为当前工作点的有限差分线性化，不预测大幅调节；到达物理上下限时为单侧差分。
- 分析设置与结果不保存进工程文件（schema v1 不变），需导出 CSV 或保存为工况。
- 水力平衡只调节与末端串联的唯一平衡阀；没有或有多个串联阀门的末端不受控（如实报告流量）。最低泵速二分假设泵速升高时各环路资用压头单调增加。不做阀门选型，不模拟动态平衡阀/压差控制器，不计算电功率；±5% 验证容差为教学阈值，不代表标准条文。

## 界面、数据和文件

- 数值失焦/Enter 提交；无效值阻止计算、保存及相关切换，Esc 可放弃该字段草稿。整数台数、温度范围已即时校验；更复杂的跨字段诊断仍主要依靠模型检查。
- 当前参数的质量单位按当前温度换算；结果/比较按各自已算密度换算。0/20/80 ℃交互路径已测，但未验证全部设备/单位组合。
- 缩小时隐藏密集标签，高倍缩放限制屏幕字级；没有全图智能避让。近距离节点仍可能重叠，可缩放/平移或调整布局；底部面板暂不能拖动调高。
- 水压图为一个拓扑循环路径，缺少多泵多源的完整路径选择语义。过期时不混合新标高与旧水头绘图。
- 表格只更新已存在的稳定 ID，不自动创建拓扑、不改变设备/局阻模式。XLSX 参数表不是完整工程重建格式。空白默认不覆盖，变化列表当前显示前 150 项，建议分批审阅。[完整用法](LIBRARY_TABLES.md)。
- 参数表限制 3 MB / 10000 行 / 256 列，XLSX 解压体积/成员数有上限；桌面工程/HTTP 请求 5 MB，每工程库 500 项。过大时拆分或删除不需要的工况；不将无法重开的文件报告为保存成功。
- SVG/PNG 是布局生成的简化示意，不保证与画布所有路由折点逐像素相同，不是施工图。
- 单份自动草稿不是无限备份；最近约 0.8 s 及尚未提交的字段可能未写入。启动读取时保留 `recovery.previous.ohn.json` 字节副本；读取/备份失败会保护旧文件、暂停覆盖，请先正式保存新工程并手动处理配置目录。不能据存储层故障测试宣称断电、所有硬件损坏或所有 Windows 文件系统已验收。
- 桌面正常退出有保存/放弃/取消；浏览器不能确认下载是否真正写盘，因此导出后仍保留未保存保护。
- 单实例仅保护同一配置目录；不是多人协作、网络文件冲突合并或无限文档窗口系统。
- 公开格式为 schema v1；未知版本拒绝。采用自主开放 JSON 格式，不兼容第三方专有二进制格式。
