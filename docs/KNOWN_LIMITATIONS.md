## 物理和数值边界

- 全网单温纯水 0–100 ℃，不支持防冻液/加压高温物性及热力耦合。
- Haaland 是 Colebrook 的近似；过渡区为明确的工程平滑约定，不是唯一真实过渡规律。
- 集中节点不显式求节点速度水头；变截面局部动能处理需要工程等效损失，不是全阶能量模型。
- 停泵按隔离处理；缺省泵含止回；并联台数只等价同型同速泵。
- 泵多项式可外推到负扬程，不自动构造真实厂家曲线；范围外有提示时必须复核。
- 理想流控没有完整设备饱和切换，只在强制流量解后检查资用压差，不足即不作为有效工作点。
- 极低流量、多个理想约束导致的奇异/病态网络尚需扩充压力测试；局部数值失败不证明全局无解。
- 仅在直接矛盾的恒扬程泵和固定边界条件下给出边界冲突证明，一般问题不会自动判定全部物理无解原因。
- 仅近似汽化筛查，不是 NPSH 或设备安全认证。水力功率没有效率数据时不能换算输入电功率。
- 可及性为局部有界搜索，不保证全局不可行或全局最优。扫描是独立稳态，不是热动态、水锤或 CFD。

## 界面和工程管理

- 数值字段提交依赖失焦/Enter；更复杂的跨字段即时诊断尚在完善。
- 质量流量显示的跨温度编辑路径尚未完整验收：改变水温后先重新计算，再用 kg/h 或 t/h 编辑末端；当前界面可能暂用旧结果密度，0 ℃ 的未计算显示也需复核。内核 SI 换算与当前温度物性独立计算，不能把 20 ℃ 路径通过推广为全部温度交互已合格。
- 缩小时统一隐藏标签，尚未实现全自动智能标签避让。
- 有框选和同类型批量属性编辑，但整套表格批量编辑/映射导入还未完成。
- 工况比较在质量流量显示下仍需补齐各工况各自密度换算；跨温度比较当前应使用 m³/h，并在导出的独立结果中按各自密度复核质量流量。不能把同温工况 E2E 通过推广为跨温度比较已完全合格。
- SVG/PNG 使用布局生成简化示意，不保证和 React Flow 的每个像素一致，也不是施工图格式。
- 水压图默认一个循环路径，尚未覆盖多泵多源复杂路径选择的完整工程语义。
- 自动保存单份恢复草稿，不是无限历史备份。未正式保存的最近约 0.8 s 变更可能丢失；退出未保存确认尚未完善。
- 没有 HACNet 工程格式资料，不能承诺直接兼容其文件。
- 工程版本 1 是首个公开格式；有迁移入口和未知版本拒绝，但尚无虚构的旧版本迁移实现。
