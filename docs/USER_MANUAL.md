# OpenHydroNet 中文用户手册

适用版本：0.1.0-preview.2。软件为离线开发预览，不是已认证工程产品。完整模型假设见 [MODELS.md](MODELS.md)。

## 1. 第一次计算

### Windows 便携包：核对、安全提示与首次启动

1. **核对完整性**：在 ZIP 所在文件夹的地址栏输入 `powershell` 回车，执行 `Get-FileHash .\OpenHydroNet-<版本>-win-x64.zip -Algorithm SHA256`，结果应与发布页面或同名 `.sha256` 文件一致；不一致请勿运行。
2. **“安全警告 / 未知发布者”**：本软件为开源预览版，没有代码签名证书，Windows 会提示“无法验证发布者 / 未知发布者”，部分电脑还会出现“Windows 已保护你的电脑”。核对一致后再选择“运行”（SmartScreen 页面为“更多信息 → 仍要运行”）。请不要关闭 SmartScreen 或杀毒软件。
3. **首次启动较慢**：刚解压后第一次启动时，杀毒软件扫描新文件，计算内核可能需要几十秒到一分钟才就绪；启动窗口会显示已等待秒数，10 秒后提示原因。之后启动通常只需几秒。启动失败时窗口会说明原因（超时、进程退出、找不到运行时或版本不一致），可点“重试”。
4. 先运行包内 `验证计算.cmd`（显示 SUCCESS 即正常），再按下列步骤完成第一次计算。


1. 启动桌面程序，选择“打开公开示例”。若上次异常退出，可选择“恢复自动保存草稿”。也可以选择“向导建立系统”，输入末端设计流量、设计压降、虚构示例泵扬程，自动生成一个闭式循环。
2. 认识布局：左侧设备和工程结构，中间管网，右侧上下文属性，底部结果、问题、水压图和工况对比。
3. 点击顶部“检查”。无错误后点击“计算”或 F5。计算在独立进程进行，界面仍可编辑；编辑后的旧结果会过期，不能冒充当前结果导出。
4. 原始公开示例应出现循环流量约 31.178 m³/h、泵扬程 18.499 m、T1 17.500 m³/h、T2 13.679 m³/h。T2 比设计流量偏低，问题列表应有需求提示。点击该提示定位末端。
5. 点击“水压图”，选择需要查看的末端。曲线为 H=z+p/(ρg)，虚线为标高；横轴为路径节点序号，不是地理距离。图上的点可定位节点。

## 2. 建模而不写关联矩阵

- 从设备区拖放一个节点，或拖放泵/阀/末端（将带入口、出口两个节点）。鼠标移到节点时显示四个端口，从端口拖向另一节点即可建立支路。默认连续创建普通管段，也可先选择其他连线模型。
- 连接预览由端口拖动提供；同一节点自连被拒绝。节点是水力连接，管线几何交叉本身不形成连接。
- 画布滚轮缩放，中键/右键拖动平移；空白处拖动框选，Shift 多选。“适配画布”恢复全图。
- 管段的实际管长在右侧输入，不取画布像素长度。移动、对齐、等距分布不会改变管长、阻力或流量需求。
- 选中普通管段可“等分管段”，原长度和局阻按比例分摊，内径/粗糙度不变；“插入阀门”保留原管长但新增一个真实阀阻力，需要重新计算。
- 反转支路方向也会反转泵/流控的实际作用方向；普通管道流量允许为负，不必为了显示方向手动反转模型。

## 3. 参数与单位

数字输入即时校验，在离开字段或按 Enter 时提交；并联台数必须为整数。无效输入不偷偷替换为默认值，阻止计算/保存及相关切换；可改正，或按 Esc 放弃该字段草稿。名称可自由编辑，稳定 ID 不随名称改变。

- 普通管道：实际长度 m、**内径 m**、绝对粗糙度 m。0.08 m=80 mm，不要把 DN80 当成精确内径。高级参数中二选一输入局部 ζ 或沿程附加倍率。
- 直接阻力：R [s²/m⁵]，ΔH=RQ|Q|，Q 单位 m³/s。
- 节点：标高 z [m]；定压边界输入**测压水头 H** [m]，不是表压 Pa。漏/补水量单位 m³/s，正漏负补。每个隔离连通分量必须有真实压力参考。
- 泵：基准多项式 H=a₀+a₁Q+a₂Q²(+a₃Q³)，相对转速为 n/n₀，并联台数指同型同速泵。提供基准额定 rpm 后可输入实际 rpm；未知时不猜额定转速。示例数据为虚构，n=0 会隔离该支路。设备库、性能点拟合、来源和有效区间见 [LIBRARY_TABLES.md](LIBRARY_TABLES.md)。
- 阀：Kv 标准水流量 m³/h @1 bar，开度 0–1；0 表示关闭，会改变拓扑。线性或等百分比特性需与设备实际资料相符。
- 用户末端：设计流量与设计压降确定定阻模型，实际流量由全网计算，不强制等于设计流量。
- 理想流控：固定流量方程和最低压差检查；压差不足时标记需求不满足，不能将强制流量当成真实有效工况。
- 顶部的流量显示单位可切换 m³/h、kg/h、t/h、L/s。编辑参数时使用当前水温密度，结果和工况比较使用每份结果各自的计算密度；0 ℃是有效输入。场景选择不偷偷改变物理输入。
- 点击画布空白可设置全网等温水温和当地大气压。闭式系统建筑高度影响静压，但不会简单增加循环泵的循环扬程。

## 4. 检查和诊断

“检查”先查输入、引用和连通分量，不代表工程符合全部规范。关闭阀门可能造成某个子网缺少真实定压参考；软件会指出对象，要求复核隔离意图，不自动增加虚构边界。

计算状态含：非法模型、边界冲突、残差未达标、超时、理想控制需求不足、合格水力解。局部求解失败不是全局无解证明。问题列表点击可定位；提示用文字和对象 ID 表示，不只依赖颜色。

公开示例的需求提示是教学阈值检查，不等同于法规不合格。高流速阈值 3 m/s 也是示例检查，不是适用于所有系统的统一设计规定。

## 5. 调节与对比

1. 当前工况计算成功后，进入“工况对比” → “保存当前工况快照”。
2. 在工程结构搜索 PU1，修改相对转速，例如 1.0→0.8，按 Enter。
3. 重新计算。选择保存的基准工况，查看流量绝对值、差值和变化比例。基准零流量时变化比例显示不可比。
4. 恢复基准工况会恢复物理模型及其原计算结果，不等于重新计算；布局不被快照强制覆盖。可删除所选快照并撤销，以控制工程体积。

快照包含完整物理输入和结果；连续修改并重新计算仍属于多个独立稳态，不是时间动态仿真。参数扫描、敏感性和可及性见第 6 节；单线展开目前仍只在 Python API/CLI。

## 6. 分析：参数扫描、敏感性、可及性与水力平衡

底部“分析”页有四个子页。所有分析都在**点击运行时冻结的模型副本**上进行，每个点都是独立稳态计算，不是时间动态；运行中可取消，单次分析最长 300 s。运行后再修改模型，结果会标为“过期”，仍可查看但不能应用。分析设置和结果**不保存进工程文件**，需要留存请导出 CSV 或保存为工况快照。可调参数只有泵相对转速和阀开度，不修改管径等设计参数。

### 6.1 参数扫描

1. 选择扫描参数，填写起点、终点、点数；可再选“第二参数”，总点数为两者乘积，单批不超过 1000 点。
2. 观测量默认为全部末端流量，可添加任意支路的流量/水头差、节点的测压管水头/表压。
3. 单参数时每个观测量一条曲线，图例可开关，不同单位的观测量可切换纵轴；双参数时横轴为第一参数，每个第二参数值一条曲线，可切换要看的观测量。未收敛的点在曲线上断开，不做插值。
4. “导出 CSV”按当前显示单位输出（UTF-8 带 BOM，可直接用表格软件打开）。

### 6.2 敏感性

勾选要比较的调节量，设定差分步长（默认 0.005）和观测量。结果是“调节量 × 观测量”矩阵：**弹性**表示参数变化 1% 时观测量变化的百分数，括号内为导数。每个观测量给出“影响最大”的调节量。参数处于物理上下限（如阀全开）时自动改用单侧差分，鼠标悬停单元格可查看。这是当前工作点附近的线性化结果，不预测大幅调节后的数值。

### 6.3 可及性

1. **约束**：默认每个末端“最小流量 = 设计流量”；可修改、删除，也可增加最大流量或最小压降（资用压头）。约束按 SI 保存，切换流量单位不会改变要求。
2. 不勾选调节量时，“检查当前工作点”判断当前输入下的结果是否满足全部约束，并逐条列出要求值、实际值和差距。
3. 勾选泵速/阀开度并设定下界、上界和**设定精度**（默认 0.01）后，“搜索可行调节（局部）”依次：找到一个满足全部约束的点 → 在保持满足的前提下尽量少调整 → 按设定精度取整并重新验算。结果页列出这三步和建议值；取整后不满足时会明确提示，并保留未取整的值。每次搜索最多 800 次计算。
4. 结论只有四种：当前工作点满足 / 不满足；在给定范围内找到满足的工作点；**未确定**。“未确定”表示局部搜索没找到，不能证明无解；“尽量少调整”是局部改进，不保证调整最小。
5. 找到可行点后可“保存为工况快照”（不改当前工程，自动设为对比基准）或“应用到当前工程”（可撤销，之后需重新计算主结果）。

公开示例：T2 实际 13.679 m³/h，低于设计 14.4 m³/h。让泵速（0.6–1.3）和两个阀（0.1–1）参与搜索，首个可行点为泵速 1.135，尽量少调整后为 1.051，按 0.01 取整为 1.06（1.05 不满足），两个阀不变。

### 6.4 水力平衡

目标：每个末端都达到设计流量。方法为流量设定法（见 [模型说明](MODELS.md) 第 8 节），是确定性计算，不是搜索。

1. **配对**：软件自动为每个有设计流量的末端找到与它串联的唯一阀门，左侧列表显示配对结果。没有串联阀门的末端不参与调节，只报告平衡后的实际流量；串联了多个阀门的末端会提示“请只保留一个平衡阀”。
2. **平衡方式**：
   - **泵速参与（变频泵）**：选择调速泵和泵速上下限，求能满足全部末端的最低泵速。此时保持全开的那一路就是**最不利环路**。
   - **泵速固定（定速泵）**：只调阀门。注意只关小阀门会使泵流量减少、扬程升高，水力功率可能反而增加；节能来自降低泵速。
3. **设定精度**（默认 0.01）：泵速向上取整，开度就近取整；取整后写回原模型重新计算，用真实计算的流量验证。**验证容差**默认 ±5%（教学阈值，可修改，不代表某一标准条文）。
4. 结果：结论、最不利环路、每个平衡阀的建议开度与验证流量（超出容差标红）、开度小于 0.2 的“阀门口径可能偏大”提示、平衡前后的泵速/扬程/流量/水力功率对比。泵速到上限、阀门全开仍不够时，提示差距最大的末端和所缺压头。
5. 与可及性相同，可“保存为工况快照”（名称为“平衡方案 N”）或“应用到当前工程”（泵速与全部开度一次写入，一次撤销即可恢复）。

公开示例：泵速参与时最不利环路为用户末端 2，泵速 1 → 0.98（最低 0.975 向上取整），调节阀 1 开度 0.22、调节阀 2 全开，两末端偏差约 −0.8%/+1.0%，泵水力功率降低约 4%；泵速固定时两阀开度为 0.20/0.40，水力功率约增加 2%。

## 7. 结果、压力和功率

节点显示 kPa(g) 为表压；绝压和算法信息保存在完整计算结果/报告中。着色可选体积流量、流速或测压水头差，色标可自动或手工上限；数字和箭头提供第二条信息通道，负流量标注反向。

泵的水头差 H_source−H_target 为负数时表示泵增压，泵扬程单独为正增压值。水力功率不是整机电功率；没有效率数据时估算输入功率显示“—”。汽化风险只是单相假设筛查，不代替 NPSH 校核。

## 8. 保存、恢复和导出

- “保存”通过系统对话框选择 `.ohn.json`。同目录临时文件 + flush/fsync + 原子替换，避免只写一半；每次保存询问位置，减少误覆盖其他工程。
- 草稿在已提交修改后约 0.8 s 保存到配置目录；启动读取时先原样保留 `recovery.previous.ohn.json`。单份备份不代替正式保存，未提交字段/最近修改可能未写入。读取/备份失败时会保护旧文件、暂停覆盖，请正式保存新工程并先手工备份配置目录。默认位置为 Windows `%APPDATA%\\OpenHydroNet`、Linux `~/.config/OpenHydroNet`，开发时 `OHN_PROFILE` 可覆盖。浏览器使用本地存储且不能确认下载真正写盘，导出后仍保留未保存保护。
- 文件使用 UTF-8 JSON（桌面接受 BOM）；损坏字节不自动替换，未知版本/失效引用/结构类型错误会明确拒绝。允许保存拓扑尚未完成的编辑草稿，但计算必须通过模型检查。桌面文件上限 5 MB，超限不写出无法重开的文件。
- “结果 CSV”导出流量、流速、水头差和功率；用户标签中的公式前缀已作表格安全转义。
- 桌面“PDF 报告”实际输出 PDF，包含输入、假设、版本、输入哈希、残差、结果和完整 SI 模型。浏览器开发模式只导出 HTML 报告。
- SVG/PNG 导出为由当前工程布局生成的简化矢量示意图，不保证与画布每个路由折点和标签像素完全相同；目前不等同于施工图导出。
- “导入参数表”提供 CSV/XLSX 字段与单位映射、变化/问题预览以及整体应用和撤销，只更新已有 ID，不猜拓扑。“参数 Excel”“结果 Excel”输出真实 XLSX；完整曲线、拓扑、工况仍应保存工程 JSON。范围及限制见 [设备库与表格手册](LIBRARY_TABLES.md)。软件使用自主开放的 JSON 格式，不兼容第三方专有二进制格式。

## 9. 快捷键与操作恢复

Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做，Ctrl+C/V 复制粘贴，Delete 删除，Ctrl+S 保存，F5 计算，Esc 取消选中。文本字段获得焦点时保留标准编辑快捷键；Ctrl+S 与 F5 会先提交当前有效数值，数值字段内 Esc 放弃未提交草稿，不同时取消设备选择。

复制选中支路时自动包含必要端点，粘贴使用新 ID 并重映射引用；删除节点同步删除关联支路。撤销重做保存稳定 ID，不重新随机生成。当前历史上限约 80 步。

计算中可“取消”；启动阶段取消/切换工程的迟到回复不归属新工程。关闭时先提交焦点字段，提供“保存后继续 / 放弃修改 / 取消”。取消保存会取消退出，保留服务；无效未提交数值不能存成旧值后退出。确认完成退出才清理恢复草稿并停止进程树。保存、退出保存和恢复不会携带与当前模型不匹配的旧结果元数据。preview.5 已在 Windows 11 真机自动驱动回归中验证取消分析、运行中关窗、保存/重开及退出清理，退出后本包进程为 0；不是用户逐项人工验收，也不是所有 Windows/崩溃场景保证，见 [验收记录](../validation/windows/0.1.0-preview.5/验收记录.md)。

## 10. 无图形界面的科研接口

```bash
PYTHONPATH=src python3 -m openhydronet.cli solve examples/closed-loop.ohn.json -o result.json
PYTHONPATH=src python3 -m openhydronet.cli batch examples/closed-loop.ohn.json --output-dir results
PYTHONPATH=src python3 -m openhydronet.cli scan examples/closed-loop.ohn.json scan.json -o scan-results.json
```

`scan.json` 示例：`[{"id":"PU1","field":"speed","values":[0.7,0.8,0.9,1.0]}]`。每点是独立稳态。

`analyze` 子命令执行与桌面“分析”页相同的请求（`kind` 为 `scan`、`sensitivity` 或 `accessibility`，字段见 `analysis.check_request`），进度以 JSON 行写入 stderr：

```bash
PYTHONPATH=src python3 -m openhydronet.cli analyze request.json -o analysis-result.json
```
Python 接口参见 `analysis.py` 与测试；可及性局部搜索未找到可行点只返回 `undetermined`，不作全局不可行结论。
