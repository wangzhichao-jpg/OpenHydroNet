# OpenHydroNet 中文用户手册

适用版本：0.1.0-preview.1。软件为离线开发预览，不是已认证工程产品。完整模型假设见 [MODELS.md](MODELS.md)。

## 1. 第一次计算

1. 启动桌面程序，选择“打开公开示例”。若上次异常退出，可选择“恢复自动保存草稿”。也可以选择“向导建立系统”，输入末端设计流量、设计压降、虚构示例泵扬程，自动生成一个闭式循环。
2. 认识布局：左侧设备和工程结构，中间管网，右侧上下文属性，底部结果、问题、水压图和工况对比。
3. 点击顶部“检查”。无错误后点击“计算”或 F5。计算在独立进程进行，界面仍可编辑；编辑后的旧结果会过期，不能冒充当前结果导出。
4. 原始公开示例应出现循环流量约 31.178 m³/h、泵扬程 18.499 m、T1 17.500 m³/h、T2 13.679 m³/h。T2 比设计流量偏低，问题列表应有需求提示。点击该提示定位末端。
5. 点击“水压图”，选择需要查看的末端。曲线为 H=z+p/(ρg)，虚线为标高；横轴为路径节点序号，不是地理距离。图上的点可定位节点。

## 2. 建模而不写关联矩阵

- 从设备区拖放一个节点，或拖放泵/阀/末端（将带入口、出口两个节点）。鼠标移到节点时显示四个端口，从端口拖向另一节点即可建立支路。默认连续创建普通管段，也可先选择其他连线模型。
- 连接预览由端口拖动提供；同一节点自连被拒绝。节点是水力连接，管线几何交叉本身不形成连接。
- 画布滚轮缩放，中键/右键拖动平移；空白处拖动框选，Shift 多选。“适配画布”恢复全图。
- 管段的实际管长在右侧输入，不取画布像素长度。移动、对齐、等距分布不会改变管长、阻力或流量需求。
- 选中普通管段可“等分管段”，原长度和局阻按比例分摊，内径/粗糙度不变；“插入阀门”保留原管长但新增一个真实阀阻力，需要重新计算。
- 反转支路方向也会反转泵/流控的实际作用方向；普通管道流量允许为负，不必为了显示方向手动反转模型。

## 3. 参数与单位

数字输入即时校验，在离开字段或按 Enter 时提交。无效输入不偷偷替换为默认值；先改正字段再计算。名称可自由编辑，稳定 ID 不随名称改变。

- 普通管道：实际长度 m、**内径 m**、绝对粗糙度 m。0.08 m=80 mm，不要把 DN80 当成精确内径。高级参数中二选一输入局部 ζ 或沿程附加倍率。
- 直接阻力：R [s²/m⁵]，ΔH=RQ|Q|，Q 单位 m³/s。
- 节点：标高 z [m]；定压边界输入**测压水头 H** [m]，不是表压 Pa。漏/补水量单位 m³/s，正漏负补。每个隔离连通分量必须有真实压力参考。
- 泵：基准多项式 H=a₀+a₁Q+a₂Q²(+a₃Q³)，相对转速为 n/n₀，并联台数指同型同速泵。示例数据为虚构，不是厂家资料。停泵 n=0 会隔离该支路。
- 阀：Kv 标准水流量 m³/h @1 bar，开度 0–1；0 表示关闭，会改变拓扑。线性或等百分比特性需与设备实际资料相符。
- 用户末端：设计流量与设计压降确定定阻模型，实际流量由全网计算，不强制等于设计流量。
- 理想流控：固定流量方程和最低压差检查；压差不足时标记需求不满足，不能将强制流量当成真实有效工况。
- 顶部的流量显示单位可切换 m³/h、kg/h、t/h、L/s。质量/体积转换使用当前水温密度。场景选择不偷偷改变物理输入。
- 点击画布空白可设置全网等温水温和当地大气压。闭式系统建筑高度影响静压，但不会简单增加循环泵的循环扬程。

## 4. 检查和诊断

“检查”先查输入、引用和连通分量，不代表工程符合全部规范。关闭阀门可能造成某个子网缺少真实定压参考；软件会指出对象，要求复核隔离意图，不自动增加虚构边界。

计算状态含：非法模型、边界冲突、残差未达标、超时、理想控制需求不足、合格水力解。局部求解失败不是全局无解证明。问题列表点击可定位；提示用文字和对象 ID 表示，不只依赖颜色。

公开示例的需求提示是教学阈值检查，不等同于法规不合格。高流速阈值 3 m/s 也是示例检查，不是适用于所有系统的统一设计规定。

## 5. 调节与对比

1. 当前工况计算成功后，进入“工况对比” → “保存当前工况快照”。
2. 在工程结构搜索 PU1，修改相对转速，例如 1.0→0.8，按 Enter。
3. 重新计算。选择保存的基准工况，查看流量绝对值、差值和变化比例。基准零流量时变化比例显示不可比。
4. 恢复基准工况会恢复物理模型及其结果；布局不被快照强制覆盖。

快照包含完整物理输入和结果；连续修改并重新计算仍属于多个独立稳态，不是时间动态仿真。单线展开、扫描、局部可及性搜索和敏感性目前主要在 Python API/CLI，不要寻找尚未实现的桌面按钮。

## 6. 结果、压力和功率

节点显示 kPa(g) 为表压；绝压和算法信息保存在完整计算结果/报告中。着色可选体积流量、流速或测压水头差，色标可自动或手工上限；数字和箭头提供第二条信息通道，负流量标注反向。

泵的水头差 H_source−H_target 为负数时表示泵增压，泵扬程单独为正增压值。水力功率不是整机电功率；没有效率数据时估算输入功率显示“—”。汽化风险只是单相假设筛查，不代替 NPSH 校核。

## 7. 保存、恢复和导出

- “保存”通过系统对话框选择 `.ohn.json`。同目录临时文件 + flush/fsync + 原子替换，避免只写一半；每次保存询问位置，减少误覆盖其他工程。
- 草稿在修改后约 0.8 s 保存到桌面用户配置目录。它是恢复入口，不代替正式保存。浏览器开发模式使用浏览器本地存储；不是 Windows 安装产品的替代。
- 打开未知工程版本会拒绝，不猜测迁移；缺失引用可保存后修复，但计算前必须通过校验。
- “结果 CSV”导出流量、流速、水头差和功率；用户标签中的公式前缀已作表格安全转义。
- 桌面“PDF 报告”实际输出 PDF，包含输入、假设、版本、输入哈希、残差、结果和完整 SI 模型。浏览器开发模式只导出 HTML 报告。
- SVG/PNG 导出为由当前工程布局生成的简化矢量示意图，不保证与画布每个路由折点和标签像素完全相同；目前不等同于施工图导出。
- Excel 映射导入和专用 XLSX 导出尚未完成，CSV 可以在 Excel 中打开，但不能宣传为已有完整 Excel 导入功能。原 HACNet 文件格式未公开，当前不支持直接打开其工程文件。

## 8. 快捷键与操作恢复

Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做，Ctrl+C/V 复制粘贴，Delete 删除，Ctrl+S 保存，F5 计算，Esc 取消选中。文本字段获得焦点时保留其标准编辑快捷键。

复制选中支路时自动包含必要端点，粘贴使用新 ID 并重映射引用；删除节点同步删除关联支路。撤销重做保存稳定 ID，不重新随机生成。当前历史上限约 80 步。

计算中可“取消”；关闭软件会终止计算进程树。进程异常时保存工程并重启，可使用草稿恢复。未正式保存的最近 0.8 s 编辑仍可能丢失。预览版尚未完善退出未保存确认，应养成显式保存习惯。

## 9. 无图形界面的科研接口

```bash
PYTHONPATH=src python3 -m openhydronet.cli solve examples/closed-loop.ohn.json -o result.json
PYTHONPATH=src python3 -m openhydronet.cli batch examples/closed-loop.ohn.json --output-dir results
PYTHONPATH=src python3 -m openhydronet.cli scan examples/closed-loop.ohn.json scan.json -o scan-results.json
```

`scan.json` 示例：`[{"id":"PU1","field":"speed","values":[0.7,0.8,0.9,1.0]}]`。每点是独立稳态。Python 接口参见 `analysis.py` 与测试；可及性局部搜索未找到可行点只返回 `undetermined`，不作全局不可行结论。
