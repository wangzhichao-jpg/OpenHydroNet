# 架构决策

## ADR-001：离线桌面与独立内核（2026-10-20）
状态：采用，预览版 0.1.0-preview.1。

- 内核：Python 3.12、NumPy、SciPy；物理模型与图形布局完全分离。使用稀疏非线性最小二乘，显式检查未缩放质量/能量残差。无云服务、无遥测。
- 界面：TypeScript + React + React Flow，标准端口连接、属性侧栏、可缩放画布；Electron 提供桌面窗口与工程文件对话框。不自研底层图形引擎。
- IPC v1：桌面主进程生成随机会话令牌，仅通过子进程环境传递，绑定 127.0.0.1 随机端口；每个计算独立子进程，任务 UUID、输入摘要、状态查询、取消、超时及窗口关闭清理。无任意文件读写 HTTP API；文件操作限 Electron 主进程。
- 工程：公开 JSON，format=`openhydronet`、schema_version=1；模型、布局、工况和设备数据随工程保存。原子落盘；前端本地恢复草稿。未知主版本拒绝，不猜测迁移。
- 核心可通过 Python API 与 CLI 独立运行；桌面无网络时仍可完整计算。
- 浏览器开发模式只接受会话令牌；开发入口不能作为最终桌面交付的替代。

选择依据：现有 Python 运行时已含 NumPy/SciPy/pytest；Node 22 可复用。相比引入新运行时或闭源水力引擎，此组合的验证、公开公式和后续维护成本较低。

## ADR-002：模型与结论边界
- H 为测压管水头 z+p_g/(rho*g)，不是总水头；节点忽略速度水头、支路损失承担动能变化的简化适用范围另述。
- SI 内核：m、s、m³/s、Pa、kg；显示单位独立。漏水为正，补水为负。
- 原说明书没有定义泵四系数公式、动态方程与可及性算法，不进行内部算法兼容承诺。
- 阀关闭从活动拓扑移除，止回采用受约束流量，不通过偷偷增加阻力模拟关闭。
- 所有参数扫描都是独立稳态工况。时间状态模型、水锤、三维 CFD 不在预览版能力之内。
- 可及性局部搜索只可报告找到可行点或搜索未找到；仅在有独立界限证明时才可报告不可行。

## ADR-003：参考资料隔离与发布
用户提供的说明书、提取正文和截图只放 `.local/reference/`，不进入公开仓库或安装包。公开矩阵仅独立概括功能和出处。示例均为人工构造；不使用真实厂家性能数据。默认 Apache-2.0，自编资源无第三方商标图形。未确认 GitHub/Gitee 账号及仓库位置前不新建远端、不推送。

## ADR-004：结果归属与文档事务（preview.2）
- 编辑参数只使用当前工程温度；结果/工况比较只使用每份结果自身物性。缺密度的质量结果显示缺数据，不假设 1000；0 ℃不使用逻辑或回退为 20 ℃。
- 正常保存、退出保存、自动恢复使用同一 `persistable()` 规则：物理输入签名不匹配时移除旧结果元数据，匹配时保留原版本/时间/残差/任务 ID；不把保存过的旧标签伪装成新计算。
- 窗口退出先刷新焦点字段，再决定保存/放弃/取消；无效未提交输入不能悄悄存成旧值。取消保存/退出不关闭计算服务；完成退出时冻结窗口、排空草稿队列、拒绝晚到草稿并终止子进程。
- 同一配置目录采用单实例。启动读取恢复草稿时先原样保留一份 `recovery.previous.ohn.json`；UTF-8/JSON 或备份错误不猜测修复，保护旧文件并要求正式保存新工程。
- HTTP 协议仍为 v1，`jobs` 可接受旧原始模型或新增 `{model, owner}`。只在同一不透明 owner 下按输入哈希去重，前端另有运行意图序号；已替换工程/取消的迟到回复不附着到新工程。取消返回进程停止检查，服务退出后拒绝新任务。

## ADR-005：自包含设备与有界表格导入（preview.2）
- 库条目是公开基准性能定义，不含网络 ID/端点/泵速/台数/阀开度。应用复制数据及来源，保留运行设置，删除库不破坏工程；未给效率则清除旧设备效率。
- 拟合采用公开二/三次升幂多项式、原始点、RMSE、有效范围和点温度，不还原未知厂家/参考软件内部公式，不认证用户数据。异步返回校验条目/工程归属，点草稿未拟合不冒充新曲线。
- CSV/XLSX 只更新现有 ID；明确列、单位与前后值，预览完整模型检查后一次应用，可撤销，不猜拓扑/型号/缺失物性。新建网络仍以画布/完整 JSON 为准。
- openpyxl/et-xmlfile/defusedxml 是离线免费依赖，来源优先清华且记录 wheel SHA-256。不执行公式，不跟随外部链接，文件/解压体积/行列数有界；不以 CSV 改后缀伪称 XLSX。
- 新产物按版本命名；preview.1 历史包和视频保留，不将本轮改动冒称已经进入旧包/旧录制，也不覆盖其校验记录。

## ADR-006：研究交付先复核，不借收敛修正物理或扩大验证声明
- CNKI 首轮资料保留原件及摘要，规范化和勘误另存私有 review 目录；全文取得、公式转述和 derived/synthetic 标签不自动等于整份数据获得公开许可。
- 文献结果反算 R 的网络仅作代数/数值回归，不声称独立验证 Darcy、绝对压力或高温物性。原文编号/表格舍入/交接转录疑点明确记录，不自动猜补。
- 已复现的高阻比默认失败列为待修复缺陷，独立守恒环流得到解不等于当前产品已修好。改进只能调整初值、尺度、算法等数值策略，保留有符号 q|q|、原输入及原残差门槛。
- 动态模型须重新核对质量/体积流量、密度、系数和单位，不能直接编入存在转录/原文代数疑点的方程。查收期间不修改用户已下载的 preview.2 Windows/网盘软件。
